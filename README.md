# Seven-deadly-sins
Seven Deadly Sins adalah cerita fantasi kultivasi tentang Wang Chen, seorang murid yang diremehkan karena dantiannya rusak dan dianggap tidak memiliki masa depan. Nasibnya berubah ketika ia menemukan altar kuno di Lembah Terlarang dan membangkitkan Pride, salah satu dari tujuh dosa purba yang tersegel di dalam dirinya.
